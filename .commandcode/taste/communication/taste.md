# Communication preferences

- Wants an end-of-work delivery report covering: project directory structure, implemented-feature checklist, verification status per feature, external services needing credentials, install/startup commands, required environment variables, seed/test instructions, test and build results, deployment instructions, and known limitations/remaining work. Confidence: 0.7
- Values honesty over polish — does not want fabricated results, invented data, or unsupported claims. Confidence: 0.75
- Expects thorough project documentation: README, API docs, environment template, seed script, health-check endpoint, and CI where feasible. Confidence: 0.55
- Non-technical audience: wants run/setup instructions spelled out concretely — exactly which folder to open and which single command to run — in copy-pasteable form, without assumed knowledge. Confidence: 0.6
