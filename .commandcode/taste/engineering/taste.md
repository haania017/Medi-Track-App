# Engineering / stack preferences

- Builds full-stack web apps on the MERN stack (MongoDB/Mongoose, Express, Node.js, React). Confidence: 0.6
- Prefers React with Vite, and Tailwind CSS or a structured CSS design-token system, on the frontend. Confidence: 0.55
- Prefers React Hook Form + Zod for forms and validation, TanStack Query for server state, and Lucide React icons. Confidence: 0.5
- Prefers JavaScript/JSX unless the project already uses TypeScript. Confidence: 0.5
- Wants REST APIs namespaced and versioned under `/api/v1`. Confidence: 0.5
- Security-minded: no hardcoded credentials, secrets via environment variables, server-side validation and authorization on every protected endpoint, and never trusting client-provided user/profile/family IDs. Confidence: 0.65
- Ships a `.env.example` with no real secrets alongside a `.gitignore`. Confidence: 0.55
- Accessibility: accessible form labels, keyboard focus support, status conveyed by text as well as colour (never colour alone), and reduced-motion support. Confidence: 0.6
